Quick Start For New Staff

Use this section when someone is opening the system for the first time or needs the shortest version of the daily workflow.

Daily workflow in plain language

  1. Login as admin.
  2. Open Lingkod Bayan if the task is about client assistance records.
  3. Open CEU Database if the task is about officials, organizations, or referral names.
  4. Open Add Record only when you need to save a new client or a new request.
  5. Open Reports only when you need summary totals, print, CSV, or graphs.
  6. Open Import Tools only for backup import or Excel import work.

Most common question: where should I go?

  • Find a client, review history, or update an assistance entry: Lingkod Bayan.
  • Add a brand-new client or save a new request: Add Record.
  • Print filtered totals or export CSV: Client Assistance Summary Report.
  • Check officials or organization names: CEU Database.
  • Check who has referrals and how many: Referral Summary inside CEU Database.
  • Import old or bulk records: Import Tools.
Best first habit

Search first before adding. This prevents duplicate client records and makes it easier to append new requests to the correct history instead of creating another profile for the same person.

Main Pages

Navigation and Main Pages

The system is split into focused pages. Each page has one main purpose, so the fastest way to work is to stay inside the page that matches the task.

Lingkod Bayan

The main operational page for client assistance records. This is where staff search the client list, open client details, manage assistance history, and move to Add Record or Reports.

Add Record

The intake page for new client records and new requests. It also detects matching clients so staff can add a request to history instead of creating a duplicate profile.

Client Assistance Summary Report

The report page for totals, filtered records, line graphs, area checks, printable summaries, and CSV export.

CEU Database

The page for CEU categories such as BARANGAY OFFICIALS, SK OFFICIALS, BHW, BPSO, BQRT, LUPON, BRGY EMPLOYEE, VAWC, and SECTORAL ORGS.

Referral Summary

A CEU sub-section that cross-checks active CEU names against Lingkod Bayan referral values. Use this only inside CEU Database.

Import Tools

Admin-only page for one-time backup import and Excel import. This page is not part of the normal daily workflow.

Lingkod Bayan

Lingkod Bayan Client Records

Use this page when the task is about finding a client, checking assistance history, editing entries, or reviewing the current record list.

Open Lingkod Bayan

Main actions on the page

  • Add Record: opens the intake form for a new client or new request.
  • Report: opens the Client Assistance Summary Report.
  • Delete All Data: removes all client records. Use only when explicitly required.
  • System Updates: opens the changelog from the main menu.

Search and filters

  • Use the main search box for client name, barangay, program, status, office, or GL code.
  • Open Filters only when you need exact filtering by Barangay, Purok, Program, Status, Office, or Requested Date range.
  • The active filter count and chips show what is currently narrowing the table.

Opening a client and using the detail view

  1. Find the client in the table.
  2. Open the detail view for that client.
  3. Review the client summary strip and latest assistance information.
  4. Use New History Entry to add another assistance request for the same client.
  5. Edit or delete individual history entries only after checking the correct date, program, and remarks.

When to use history instead of a new client

If the person is already in Lingkod Bayan and the new request belongs to the same client profile, do not create another client row. Add a new history entry instead so the profile stays clean and all requests remain together.

Important warning

Delete All Data is not a cleanup tool for ordinary work. Use it only if an admin truly intends to wipe the full client assistance dataset.

Intake

Add Record

Use Add Record for intake. This page can either create a new client record or attach a new request to an existing client through history.

Open Add Record

What the form is divided into

  • Section 1: Office / Organization
  • Section 2: Client Information
  • Section 3 and later sections: request, medical, guarantee, event, and related details depending on the selected program
  • Final action: Save Record

Existing client match behavior

  • If the name matches an existing client, the page shows a notice.
  • You can use Add Request Details so the client profile stays on the main record while the new request is saved in history.
  • This is the safest way to prevent duplicate client profiles.

Duplicate request protection

The form checks if the same client already has the same request date and program saved. If it does, save is stopped so staff can review the existing history entry first.

Program-specific fields

Required fields change depending on the selected program. Medical-related requests will show fields like Requesting For, Patient Status, Client Times, Hospital, and status-specific dropdowns such as Transport Service Status or OP Assistance Status.

Best practice for Add Record

Finish the client identity first, then choose the program carefully, and only then fill the request-specific fields. That order avoids missing required fields and wrong program status combinations.

Reporting

Client Assistance Summary Report

Use the report page for totals, filtered records, breakdown tables, graphs, print, and CSV export.

Open Report Page

Top buttons

  • Back: returns to Lingkod Bayan records.
  • Print: prints the current filtered report, not the whole raw database.
  • Export CSV: exports the current filtered records to CSV.
  • Line Graphs: shows or hides report graphs.

Filters available on the report

  • Search
  • Month
  • Year
  • Barangay
  • Type
  • Status
  • Office
  • Source
  • Category
  • Priority

How to read the page

  • The summary cards show totals like total people assisted, distinct assistance types, pending cases, and completed cases.
  • The Filtered Records table is view-only and shows the exact client rows included in the current report filters.
  • Breakdown tables such as Assistance by Barangay or Assistance by Type can be clicked to show the records behind a total.

Printing and exporting rules

  • Print uses the current filtered records.
  • The print view includes the active filters, so staff can see what was set to All and what was narrowed down.
  • If 8 filtered records are visible, 8 records should be what appear in the report print view.
Helpful check before printing

Look at the Filtered Records section first. If the rows shown there are correct, the printed report should match those same filtered rows.

CEU Workspace

CEU Database

Use CEU Database for category-based records such as BARANGAY OFFICIALS, SK OFFICIALS, BHW, BPSO, BQRT, BRGY EMPLOYEE, LUPON, VAWC, and SECTORAL ORGS.

Open CEU Database

How the page is organized

  • Category buttons switch between CEU datasets.
  • All lets staff search across all categories at once.
  • Each category has its own search and keeps the original table layout inside barangay accordions.

Main admin actions

  • Add CEU Record: opens the CEU editor modal.
  • Refresh Data: reloads the CEU data from Supabase.
  • Referral Summary: opens the referral summary inside the CEU page.

Searching and browsing

  • Search first by name, barangay, position, organization, address, or other relevant CEU details.
  • Open the barangay accordion only when you need the actual row list.
  • The summary line above each accordion shows how many records are currently visible.

Editing and deleting CEU rows

Use the action controls inside the category tables for updates or deletion. Because CEU data lives in Supabase, treat it as shared data and confirm the target category before saving changes.

Important setup note

If CEU data is missing, the status message usually means Supabase is not connected, the admin session is missing, or the CEU setup/seed SQL still needs to be run.

CEU Referral Checks

Referral Summary

Referral Summary is part of CEU Database. It compares active CEU names with Lingkod Bayan referral values so staff can see who has referrals and how many.

What the page shows

  • Tracked names
  • Total referrals
  • Names with referrals
  • Top referral name
  • Row-by-row counts for the current filtered summary

Filters available

  • Search by name, barangay, category, role, or organization
  • Category
  • Barangay
  • Referral Count
  • Rows Per Page

Print and PDF actions

  • Print Summary: prints the current filtered referral summary in the same tab.
  • Download PDF: creates a PDF version of the filtered summary.
  • Print Selected: prints only the checked rows.

Row selection

  • Use the row checkboxes when you need only specific rows.
  • The page checkbox helps with current-page selection.
  • The selection status text tells you how many rows are selected and how many are still visible in the current filters.
How to interpret the heat color

Zero referrals stay white. Once the count starts at 1 and goes up, the color shifts across the referral heat scale until higher counts move toward red.

Admin Tools

Import Tools

This page is for bulk or one-time import work. It is separated from daily client records work on purpose.

Open Import Tools

One-Time Supabase Import Tool

  • Use this only when preserved browser backup records must be moved into the shared Supabase database.
  • It is not for normal daily entry.
  • Confirm the source backup first before importing.

Excel Import Tool

  • Download the template first.
  • Do not change the Excel column headers.
  • Import the workbook after filling the rows correctly.
  • Repeat requests are merged into client history when possible.
Important warning

Import Tools affects many rows at once. If the task is only one client or one request, do not use this page. Use Add Record or the client history editor instead.

Separate Utility

Local Form

The local form is separate from the authenticated admin workflow. Treat it as a standalone capture tool, not the main admin database screen.

What it is for

It keeps answers locally in the browser and is useful when a standalone, form-like intake flow is needed outside the normal admin record management screens.

What it is not for

It is not the daily page for managing Lingkod Bayan client history, CEU records, or referral summary reporting.

Support

Troubleshooting and Best Practices

Use this section when something does not look right, a page is empty, or the result does not match the expectation.

If data takes a few seconds to appear

The system now shows loading screens during major page changes, especially when moving between Lingkod Bayan and CEU Database. A short wait can still happen while Supabase data is loading.

If CEU or Lingkod Bayan looks empty

  • Check that the admin session is still active.
  • Check the status message shown on the page.
  • For CEU, verify that Supabase setup and seed work were completed.
  • Try Refresh Data before assuming the records are gone.

If Add Record blocks save with a duplicate warning

Do not force another identical client request with the same date and program. Search the existing client first and review that client's history entry.

If a print result looks wrong

  • Check the filtered records or filtered summary before printing.
  • Confirm the active filters.
  • For Referral Summary, know whether you clicked Print Summary or Print Selected.

Best practices for clean data

  • Search before adding.
  • Use history for repeat requests on the same client.
  • Use CEU names as the reference for referral-related entries.
  • Review filters before printing, exporting, or reporting totals.
  • Use Import Tools only for bulk or one-time admin work.
