# KarlForge Portfolio

Personal portfolio website for Karl Matthew F. Degala.

## How To Edit

- Homepage content: `index.html`
- Main styling: `css/style.css`
- Project list and project details: `js/projects-data.js`
- Skills modal content: `js/skills-data.js`
- Project detail pages: `projects/[project-slug]/index.html`
- CV page: `cv/index.html`
- Images and screenshots: `assets/images/`
- PDF files and documents: `assets/docs/`

## How To Preview Locally

Open `index.html` directly in a browser, or run a local static server from this folder.

## GitHub Pages

This site is designed to publish from the repository root using GitHub Pages.

Recommended Pages setting:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`

After saving, GitHub will publish the site at:

```text
https://Karlthegreatprogrammer.github.io/Online-Platform/
```

It may take a few minutes for updates to appear after pushing changes.
